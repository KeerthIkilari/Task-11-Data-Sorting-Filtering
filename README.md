Task 11: Basic Data Sorting & Filtering

Project Overview

This project demonstrates basic data sorting and filtering techniques using Python in Google Colab. The project uses a Superstore Sales Dataset to analyze sales information and answer business questions.

Objective

To sort and filter a dataset and identify useful business insights through data analysis.

Tools & Technologies

- Python
- Google Colab
- Pandas
- Matplotlib

Dataset Information

Dataset Name: Superstore Sales Dataset

The dataset contains 20 orders and 6 columns:

- Order_ID
- Product
- Category
- Region
- Sales
- Quantity

Tasks Performed

1. Sorted sales from highest to lowest.
2. Sorted product names alphabetically.
3. Filtered Technology category products.
4. Filtered East region orders.
5. Filtered sales above 10,000.
6. Filtered quantity greater than 2.
7. Applied multiple filtering conditions.
8. Created category-wise and region-wise sales summaries.
9. Created sales visualization charts.

Business Questions

1. Which product has the highest sales?
2. Which region has the highest total sales?
3. What is the total sales amount?
4. Which category has the highest sales?
5. How many orders have sales above 10,000?

Project Files

- "Task_11_Data_Sorting_Filtering.ipynb" – Google Colab notebook.
- "Superstore_Sales_Dataset.csv" – Dataset.
- "Task_11_Data_Sorting_Filtering_Report.pdf" – Project report.

Conclusion

This project helped demonstrate how Python and Pandas can be used for sorting, filtering, and analyzing sales data. Matplotlib was used to visualize sales information through charts.
